# 项目总体企划与产品基线

- 文档版本：V0.1
- 日期：2026-07-29
- 适用代码版本：0.1.x
- 状态：工程基线
- 工作名称：Event Forecast Lab

## 1. 项目定义

本项目是一个娱乐型事件预测与游戏化互动平台。平台接入公开事件市场或可信数据源，把事件标准化后提供给用户进行模拟预测。用户使用无现金价值的免费积分建立虚拟持仓，并通过预测准确度、风险调整收益、赛季排名、成就和社交互动获得娱乐体验。

Polymarket 是首个 Provider，不是平台本身。长期目标是支持：多外部数据源、体育与公共数据、平台官方事件、用户创建事件、私人房间、企业内部预测、多种计分策略，以及 Web、移动端、Bot 和 B2B API。

## 2. 不可突破的产品边界

当前娱乐平台：

- 不接收真实货币或加密货币
- 不出售可用于预测的积分
- 积分不能提现、转让或兑换实物
- 不提供真实 Polymarket 下单
- 不保管钱包、私钥或用户资产
- 不按用户输赢向代理分成
- 不向用户承诺预测收益

真实资金、持牌博彩或受监管预测市场属于独立系统。未来即使合法开展，也必须通过独立法人、独立账户、独立账本、KYC/AML、资金隔离和单独 API 连接，不能把免费积分账本直接改造。

## 3. 目标用户

1. 喜欢新闻、体育、科技、财经和加密事件的人；
2. 希望通过游戏方式练习概率判断的人；
3. 希望查看中文事件规则和概率变化的人；
4. 对预测能力、Brier Score 和排行榜感兴趣的人。

## 4. 核心用户闭环

```text
注册 → 获得免费积分 → 浏览并理解事件 → 请求短期报价 → 建立模拟持仓
→ 查看概率变化 → 提前退出或等待结算 → 获得积分与评分 → 排行榜/任务/赛季/社交
```

## 5. 产品模式

底层使用份额与持仓模型：价格位于0到1；投入积分除以价格得到份额；正确结果每份结算为1积分，错误结果为0。前端可显示为“投入积分”和“潜在回报”。

这样天然支持提前退出、部分退出、追加持仓、价格历史、多结果市场、多种评分和其他Provider。

## 6. 平台能力域

### 身份与用户

登录、资料、设备、权限、年龄和地区标记、冻结、注销、数据导出。

### 市场与内容

外部Provider、本地标准市场、规则版本、多语言、市场审核、敏感内容分级、用户市场。

### 预测与持仓

报价、幂等下单、份额、持仓、提前退出、市场封盘、限制与争议证据。

### 虚拟资产

多账户、多资产代码、双重记账、冻结、冲正、奖励、赛季和经济监控。

### 结算

结果检测、人工确认、证据链、版本、批量入账、失败重试、冲正和重算。

### 游戏化和社交

每日奖励、任务、成就、连胜、赛季、段位、团队、关注、好友、评论、动态、私人房间、举报和审核。

### 商业化

数据会员、权益、广告、企业API、白标；付费能力不能购买预测本金。

### 平台治理

功能开关、配置、审计、风控、运营后台、通知、数据分析和内容治理。

## 7. 第一阶段范围

必须完成：市场同步和标准化、管理员审核、身份、免费积分、报价、模拟预测、持仓、结算、账本流水、基础排行榜、审计、功能开关、监控和备份。

暂不上线但预留：评论、好友、房间、团队、用户市场、任务、成就、赛季、AI摘要、多语言、会员、B2B API、移动端、多Provider。

## 8. 虚拟经济原则

积分来源必须可审计：新用户赠送、每日补给、任务/赛季奖励、市场结算、经审批补偿。积分消耗包括建立模拟持仓和不影响公平的娱乐性功能。

必须监控总发行量、日增发与回收、人均余额、财富集中度、破产率、多账号异常、大额发放和赛季重置影响。所有参数配置化并保留历史。

## 9. 成功指标

技术：账本不平0次、重复结算0次、外部源中断可降级、严重故障可回滚、可从备份恢复。

产品：首次预测转化、首次预测时间、D1/D7/D30留存、每周活跃预测用户、每用户预测次数、赛季参与率、规则争议率。

经济：积分发行消耗平衡、破产保护使用率、财富集中度、异常账号比例。

## 10. 两人工作方式

用户负责产品选择和验收、按手册执行环境和账号操作、记录真实错误、保管密钥、不跳过检查。

AI/Codex负责协助文档、架构、代码、测试、API、自检、诊断、迁移、PR和故障定位。无法共同解决的问题通过标准Support Bundle向外部工程师求助。
