## 里程碑

### M0 工程基线

已完成：文档、Monorepo、CI、Docker、自检、核心数据模型。

### M1 数据闭环

目标：同步、标准化、实时价格、价格快照、后台审核和只读展示。

当前子进度：

- M1.1 Event Keyset 目录同步：完成基线；
- M1.2 正式迁移、PostgreSQL 自动验收和 Advisory Lock：完成；
- M1.3a CLOB WebSocket、动态订阅和断线恢复：完成客户端基础；
- M1.3b Worker Token Source、REST 行情快照、周期对账、价格持久化和 current cache：下一阶段；
- M1.4 关闭/结算滚动回查：待完成；
- M1.5 同步后台和只读页面：待完成；
- M1.6 监控、告警和恢复演练：待完成。

当前工程评估：整个 M1 约 62%。

### M2 预测闭环

身份、免费积分、报价、预测、持仓、结算、流水。

### M3 运营闭环

排行、每日奖励、通知、后台、风控、分析。

### M4 游戏化

赛季、任务、成就、好友、房间、团队。

### M5 平台化

多 Provider、用户市场、AI、会员、B2B API、移动端。

## 文档同步要求

每个里程碑变更必须更新：

- `AGENTS.md`；
- `docs/AI_PROJECT_HANDOFF.md`；
- `docs/CURRENT_STATE.md`；
- 受影响专项规范；
- 零基础施工手册；
- 排错和外部求助说明；
- Changelog；
- GitHub Issue 和 PR。

每个里程碑必须通过测试、迁移、文档、监控和恢复演练，不以“页面能点”作为完成标准。
