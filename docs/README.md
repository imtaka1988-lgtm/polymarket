| `DEVELOPMENT_WORKFLOW.md` | 所有参与者 | 需求、开发、测试、发布和文档流程 |
| `TROUBLESHOOTING_AND_SUPPORT.md` | 负责人、外援工程师 | 自查、故障定位与外部求助 |
| `SECURITY_OPERATIONS.md` | 运维、工程师 | 安全、权限、备份、降级和应急 |

## 文档完成标准

功能未同步更新文档，视为未完成。每份重大文档都应记录：当前版本、更新时间、适用代码版本、维护模块和状态。
